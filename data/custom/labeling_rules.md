# กติกาติดป้ายชุดข้อมูลที่จัดทำเอง

ใช้กับทุกประโยคในชุดที่จัดทำเอง (ทุกค่า `source`) ใช้กติกาเดียวกันตลอด
ป้ายมี 4 ประเภทเหมือน Wisesight: pos / neu / neg / q

ติดป้ายจากความหมายของข้อความตามกติกานี้ ไม่ลอกป้ายของ Wisesight
(ป้ายใน Wisesight ติดไม่สม่ำเสมอในบางกรณี เช่น ข้อความนัดหมายถูกติดทั้ง pos และ neu)

## กติกา

| กรณี | ป้าย | ตัวอย่าง |
| ----- | ----- | ----- |
| ถามเพื่อขอข้อมูลหรือคำตอบ (ราคา สาขา รุ่น วิธีใช้ สถานะ) ไม่ต้องมี `?` | q | "รีฟิลราคาเท่าไหร่ค่ะ" / "โคราชมีสาขาไหนบ้างค่ะ" |
| ชวน ขอร้อง หรือถามเชิงชวนที่ไม่ได้ขอข้อมูล | pos | "กินป่าว" / "พาไปกินหน่อยยย" |
| นัดหมายหรือบอกวันเวลาเฉยๆ ไม่มีอารมณ์ | neu | "วันพุธเจอกัน" |
| ข่าว โฆษณา ประกาศ ข้อมูล หรือคำบอกเล่าที่ไม่มีอารมณ์ชัดเจน | neu | พาดหัวข่าวรถรุ่นใหม่ / โพสต์โปรโมชันร้านอาหาร |
| คำถามที่แฝงความไม่พอใจหรือร้องเรียน | neg | "ทำไมส่งของช้าจัง" |
| คำถามเชิงวาทศิลป์ที่ไม่ต้องการคำตอบและแฝงความไม่พอใจ | neg | "ใครจะไปกินอ่ะ" |
| คำถามเชิงวาทศิลป์ที่ไม่มีอารมณ์ชัดเจน | neu | |
| ข้อความที่ชมและติปนกัน ติด neg เสมอถ้ามีคำติ | neg | "อาหารอร่อยแต่พนักงานแย่มาก" |
| ข้อความที่มีแต่อีโมจิ | ไม่เก็บ | |
| ถามวิธีแก้ปัญหาเฉยๆ ไม่มีคำบ่น | q | "ติดต่อขอดูกล้องยังไงคะ พอดีของหายเหมือนกัน" |
| ถามวิธีแก้ปัญหา แต่มีคำบ่นหรืออารมณ์ไม่พอใจชัดเจน | neg | "แฟลช ทำของหาย…ทำไงดีครับ เค้าเตอร์ไม่ทำอะไรให้เลย" |
| ผิดหวังหรือเสียดายเรื่องของตัวเอง ไม่ได้ติธุรกิจ | neu | "อยากเรียน แต่ไม่ว่าง 2 วันนั้นพอดี แงงง" / "ไม่ทันน ติดอีกงาน 🥲" |
| แสดงความสนใจสินค้าหรือบริการเฉยๆ | pos | "สนใจครับ" |
| แสดงความสนใจและถามข้อมูลด้วย | q | "สนใจ สอบถามราคา" |
| ข้อความสั้นที่ต้องเห็นโพสต์ต้นทางจึงจะเข้าใจความหมาย | ไม่เก็บ | "เรียน" (ใต้โพสต์คอร์สเรียน) |

## หมายเหตุ

- อีโมจิที่ปนอยู่ในประโยคเก็บได้ ติดป้ายจากความหมายของทั้งประโยค (เช่น "อยากกินอ่ะหมู 😣😣😣")
- ถ้าข้อความทั้งชวนและบอกวันเวลา (เช่น "พุธนี้ไปกินกันป่าว") ให้ถือว่ามีการชวนและติด pos
- ห้ามใช้ดาวรีวิวเป็นป้ายอัตโนมัติ ต้องอ่านแล้วติดตามกติกานี้
- ห้ามเก็บชื่อหรือข้อมูลระบุตัวผู้ใช้ ตัดชื่อ เบอร์โทร ออกจากข้อความ
- ถ้าคำถามในข้อความเป็นการเล่าว่าไปถามคนอื่นมา (เช่น "เลยถามว่าถ้าหายแล้วจะต้องทำยังไง เขาบอก…") ไม่นับเป็นคำถามถึงผู้อ่าน ให้ติดป้ายจากเนื้อหาหลักของข้อความ
- กติกา 6 ข้อท้ายตาราง และหมายเหตุข้อบน เพิ่มเมื่อ 2026-11-05 ระหว่างตรวจป้าย (รายละเอียดแถวที่แก้ดู `sources.md`)
- กรณีที่ไม่เข้ากติกาข้อใด ให้จดไว้และเพิ่มกติกาที่นี่ ห้ามติดป้ายตามความรู้สึกชั่วคราว
